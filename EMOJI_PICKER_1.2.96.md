# Emoji picker — v1.2.96

- Added a composer emoji picker with categorized smileys, hearts, gestures, people, animals, nature, food, activities, travel, objects, symbols, and flags.
- Includes a broad Unicode emoji set with Nigerian and other country flags; glyph appearance depends on the device's installed emoji font.
- Emoji selection inserts the chosen character into the current message draft. Existing draft persistence and send behavior remain in use.
- Picker and individual insertion actions have accessibility labels; unit tests validate catalog coverage and the composer controls.

## Limits

This is a curated, broad palette, not a guarantee that every Unicode emoji sequence or newly released emoji is included on every OS. Some emoji may display as missing glyphs on older devices. The native keyboard remains available for the full system emoji set.
