# ZannyChat 1.2.20

This release adds a premium Shared Media Hub to each conversation: Photos, Files, and Links, with pagination, clear empty/loading/error states, safe URL extraction, and full-screen photo viewing.

Run frontend unit tests with `npm run test:unit`. Static parsing and archive integrity checks are recorded in the release package. Native builds, live Supabase integration, and physical-device checks remain required before production release.
