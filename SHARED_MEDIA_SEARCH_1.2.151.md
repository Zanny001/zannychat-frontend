# Shared Media Search — 1.2.151

- Added in-screen search for shared photos, files, videos, audio, and links.
- Search matches available names, message text, dates, sender names, link titles/hosts/URLs, and media types.
- Added an accessible no-results state with a one-tap Clear search action.
- Search filters the currently loaded items only; it does not imply a server-wide search across unloaded history.
- Added utility regression tests for case-insensitive matching, supported fields, empty queries, and invalid input.
